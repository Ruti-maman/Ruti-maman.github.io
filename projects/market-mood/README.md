# MarketMood - חנות מקומית לפי מצב רוח

## תיאור הפרויקט
אפליקציית חנות מקומית (Offline) המציעה מוצרים מותאמים אישית לפי מצב הרוח של המשתמש.
המערכת כוללת צד משתמש וצד מנהל לניהול מלא של המוצרים, המשתמשים וההזמנות.

## טכנולוגיות
- **TypeScript** - שפת התכנות הראשית
- **HTML5 & CSS3** - ממשק משתמש רספונסיבי
- **LocalStorage** - שמירת נתונים מקומית
- **Web Audio API** - מוזיקת רקע אינטראקטיבית
- **Regex** - ולידציה מתקדמת לטפסים

## תכונות עיקריות

### צד משתמש
- בחירת מצב רוח (שמח, עצוב, נייטרלי, כועס, אהבה)
- הצגת מוצרים מותאמים למצב הרוח
- עגלת קניות מתקדמת
- מעקב אחר הזמנות
- ווידאו ומוזיקה לפי מצב רוח
- ציטוטים מוטיבציוניים אינטראקטיביים

### צד מנהל
- ניהול מוצרים (הוספה, עריכה, מחיקה)
- ניהול משתמשים
- מעקב אחר הזמנות
- דשבורד סטטיסטיקות

### פיצ'רים נוספים
- מערכת התחברות והרשמה
- Regex Validation לכל הטפסים
- חיפוש, סינון ומיון מתקדמים
- טיימרים (setTimeout/setInterval)
- נגישות מלאה (labels, aria, RTL)
- רספונסיביות מלאה

## התקנה והרצה

### דרישות מקדימות
- Node.js (גרסה 14 ומעלה)
- דפדפן מודרני (Chrome, Firefox, Edge)

### התקנה
1. פתח את התיקייה בטרמינל
2. התקן תלויות:
   ```bash
   npm install
   ```

3. קומפל TypeScript:
   ```bash
   npx tsc
   ```

### הרצה
1. פתח את הקובץ `index.html` בדפדפן
   - לחיצה ימנית → Open with → Chrome/Firefox/Edge
   
2. או השתמש ב-Live Server (מומלץ):
   - התקן Live Server Extension ב-VSCode
   - לחץ ימני על `index.html` → Open with Live Server

## תכונות טכניות מתקדמות

### LocalStorage
- כל הנתונים נשמרים מקומית
- נשמרים: משתמשים, מוצרים, עגלה, הזמנות
- המידע נשמר גם לאחר רענון הדף

### Regex Validation
- אימייל: `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`
- סיסמה: `/.{4,}/`
- שם: `/^[\u0590-\u05FFa-zA-Z\s]{2,50}$/`
- מוצרים: שמות, מחירים, תיאורים

### טיימרים
- `setTimeout`: בועות ציטוטים, הודעות, ניתוב
- `setInterval`: שעון בזמן אמת, עדכון עגלה
- ניקוי טיימרים: `clearTimeout`, `clearInterval`

### מיון, חיפוש וסינון
- חיפוש בשם/תיאור/קטגוריה
- סינון לפי קטגוריה ומצב רוח
- מיון לפי פופולריות, חדשים, אקראי

## נגישות
